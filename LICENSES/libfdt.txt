libfdt.spdx preserves the imported distribution's package metadata, including
its MIT-licensed wrapper package. That wrapper is not included here; the
libfdt source files listed above carry their own dual-license identifiers.

Local integration replaces hosted C headers with nuvix headers and omits
device-tree overlay support. Include <nuvix/libfdt.h> for the supported API.
